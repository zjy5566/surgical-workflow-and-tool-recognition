3. DATA CONFIGURATION
--------------------------------------------------------------------------------
Before running the pipeline, you must link your local Cholec80 dataset:

1. Navigate to: tf_cholec80/configs/config.json
2. Update the "cholec80_dir" field to point to your local dataset directory.
3. Ensure your dataset directory contains the following subfolders:
   - /frames/
   - /phase_annotations/
   - /tool_annotations/


4. REPRODUCING RESULTS
--------------------------------------------------------------------------------
The entire pipeline is automated. Run the following command in the project root:

    python run.py

Execution Flow:
The script executes the following steps sequentially:

I.   Task A Training: Trains CholecAutoModel for phase and temporal estimation.
II.  Baselines: Trains the ToolBaselineModel (visual-only).
III. Task B Variants: Trains guided models, concluding with the 
     Prediction-Guided Multi-Task model (using Task A outputs).
IV.  Global Testing: Evaluates all saved .pth checkpoints against the test set.
V.   Visualization: Generates frame-by-frame comparison plots for test videos.


5. MONITORING RESULTS
--------------------------------------------------------------------------------
After the pipeline completes, verify performance via these outputs:

A. Training Logs and Checkpoints
   - Logs: Located in checkpoints_A/, checkpoints_B/, checkpoints_B_Multi/, 
     and checkpoints_baseline/. Documents Loss and F1/mAP per epoch.
   - Plots: .png files in checkpoint folders (e.g., task_b_pure_metrics.png) 
     display Loss and Accuracy curves.
   - Models: Best weights are saved as .pth files (e.g., best_task_a.pth).

B. Evaluation Metrics
   - Check the project root for test_results_[TIMESTAMP].log.
   - Contains side-by-side comparisons of all models (Macro mAP, mF1, etc.).

C. Qualitative Visualization
   - Located in the visualization/ directory.
   - Timeline plots (e.g., comparison_video_49_Part_1.png) show Ground Truth 
     vs. predictions for all five model variants across the surgical duration.
